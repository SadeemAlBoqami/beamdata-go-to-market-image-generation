# beamdata-go-to-market-image-generation

Capstone project for evaluating commercial and open-source
image-generation models for marketing applications.

## Objectives

- Benchmark commercial image-generation APIs
- Benchmark open-source image-generation models
- Compare quality, latency, cost, reliability, and VRAM usage
- Test brand-style adaptation using LoRA
- Evaluate social-media aspect ratios
- Build a side-by-side human evaluation interface

## Candidate Models

### Commercial
- OpenAI gpt-image-2        
- FLUX.2 Pro
- Gemini 3.1 Flash Image
### Open Source
- FLUX.2 Klein 4B
- Stable Diffusion 3.5 Medium
